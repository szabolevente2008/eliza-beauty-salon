# Eliza Beauty Salon – weboldal

Vikingo AI-webfejlesztés tanfolyami házi feladat: egy kitalált kozmetikai szalon négyoldalas weboldala, Figma nélkül, AI-jal tervezve és építve.

- **Oldalak:** Főoldal, Kezelések, Rólunk, Kapcsolat, Adatkezelési tájékoztató
- **Technika:** statikus HTML + saját CSS (`css/style.css`) + kevés JavaScript (`js/main.js`), Google Fonts (Cormorant Garamond, Jost)
- **Űrlapok:** Netlify Forms (`idopontkeres`, `hirlevel`)
- **Képek:** Unsplash (ingyenes licenc), WebP, 800 és 1600 px széles változatban
- **Folyamat:** `/tervezes` → brief (`.webprojekt/brief.md`) → `/generalas` 3 koncepcióval (`koncepciok.html`) → a választott irány („A csendes szalon”) kiépítése

Élő oldal: https://eliza-beauty-salon-budapest.netlify.app/

Helyi előnézet: `python -m http.server 4341`, majd http://127.0.0.1:4341/

A telefonszám és az e-mail cím kitalált adat.
